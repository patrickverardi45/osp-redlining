# FieldRoute (TrueLine v2) — Council Report

**Author:** Council Report Author (acting Product Lead + QA)
**Date:** 2026-06-27
**Branch:** `feat/truelinev2` (backend HEAD `9ee706a`); web repo `trueline-web-experience` (separate)
**Scope:** Product, workflow, placement, closeout, and staging audit of the v2 product path — does it "work like v1" (one job, one page, upload → redlines → review/correct → closeout → print/save/export) on the safer v2 engine, with no fake outputs.

---

## How to read this report

The product goal is **"a real user completes the workflow without anyone explaining where to click."** HTTP 200 is not proof. This report grades against that bar.

**Honest headline:** the *engine* and the *backend* are in good shape — the deterministic 50/58 frontier is provably isolated from the generic lane, confidence is now genuinely earned (LOW on real linework, no fake AUTO), the export gate is unified, the closeout backend is more honest than v1, and the staging supervisor self-heals. The product **fails at the seams a real user touches**: the upload workspace has no front door, an uploaded bore log secretly requires manual re-entry before the engine will run, and the guided demo dead-ends before closeout. None of the do-now fixes require touching the engine, renderer, fixtures, or the deterministic path.

Severity legend: **blocker** = stops a real user cold; **high** = breaks or badly confuses the core flow; **medium** = friction/ambiguity; **low** = polish/copy.

**One correction to the source audit applied here (verified, not guessed):** the QA-matrix prediction that "Print/Save leaks the whole page (no `@media print` scoping)" is **contradicted by the actual code**. `globals.css:43-60` *does* implement `@media print { body * { visibility:hidden } #closeout-print, #closeout-print * { visibility:visible } ... }`, scoping print to `#closeout-print` and hiding `details`. The uxAudit and closeoutAudit (which say scoping is present) are correct; that one qaMatrix prediction is stale. It is **not** carried as a finding below.
